# 智慧树平台操作经验（实测）

课程示例：生态文明与低碳发展（智慧树 2026 秋冬），课程 ID 2097228318614908928，班级 ID 272143。

## DOM 定位与填答

- 题号定位用 `getByRole('treeitem',{name:String(n),exact:true})`，点击后核对 `.letterSortNum` 是否为对应题号，避免页面异步更新时填错题。
- 单选/判断答案在 `role=list` 中，多选在 `role=group` 中；用准确选项文字定位，曾因只搜全文而误匹配题干。
- 多选选中后再点会取消；恢复时只补未答题，不要整组盲目重填。先读勾选状态。
- 多选题点行内空白只产生 hover，需「点文字 + 按空格」才真正勾选。
- 单选选中图标含 `.checkedIcon`；答题卡 treeitem 下 `.no-answer` 表示未答、`.answer` 表示已答。

## 保存与提交

- **平台常在切换题目时保存当前选择**：填完最后一题后切回第 1 题，再检查答题卡，解决最后一题显示未保存的问题。
- 确认无未答项后点「提交作业」，读取最终评分页「总题数 N 已答对 M」，之后才更新 JSON；单凭点过提交不算，曾出现「还有题目没有完成哦！」。
- 解析页「重新答题」需连点 2-3 次才生效。

## 导航与加载

- 课程页「去提升」先打开中间面板，再点「去提升 →」进入练习；课程目录 role=button，名称「知识模块 + 模块名」，有单元再展开「知识单元： + 单元名」。
- 页面标题更新早于实际内容，`.el-loading-mask` 可能仍在；先等加载完成，不要看到标题就以为入口就绪。
- 截图必须用视口模式（`full_page:false`），全页截图与点击坐标是不同坐标系。

## 稳定性 / token 控制

- 长脚本 30 秒超时会导致 kernel 重置、大量浪费 token：小批次执行、保存断点、单次操作控制在可完成范围，避免一次串两组全部填答。
- 跨答题域与结果域跳转时会短暂发生 CDP 超时；保留句柄、检查当前标签、稍后重试，不要立即重复导航导致丢进度。
- 不要用 `new Function` 从文件恢复辅助函数（环境禁止字符串生成代码），可直接定义必要小函数或走模块机制。
- 浏览器工具可能限制 evaluate 为只读 DOM，不能绕过规则用 evaluate 点击，应优先用受支持的 locator 点击。

## 答案匹配规则

- 重刷时题序会打乱，答案必须按**题干文字**匹配，不能按题号。
- 候选答案若未经过评分验证，应明确标注「未验证」，不要冒充平台参考答案或保证全对。
