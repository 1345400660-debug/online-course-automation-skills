# 智慧树在线答题

## 用途

在智慧树（知到）学生端课程内，自动完成「必学资源」浏览与「知识点练习 / 提升掌握度」的在线答题：
按题干文字匹配答案、批量填答、切题触发保存、检查漏题、提交并读取评分，最后把结果写入本地进度
断点文件。核心目标是**用最少 token 完成一轮答题**，不追求满分、不因错题反复重刷。

## 适用场景

- 需要把一门智慧树课程的全部「必学」资源走完，或对每个可练习知识点各完成一轮练习。
- 需要重刷「掌握度」低于阈值（如 70%）的知识点，且重刷时题序会打乱、只能按题干匹配答案。
- 需要接续上一会话/上一 AI 未完成的答题任务（存在进度断点 JSON 与交接日志）。
- 需要批量完成知识点的「单元测试」或「AI 能力测评」并读取即时判分。

## 输入

- 课程入口 URL（形如 `https://ai-smart-course-student-pro.zhihuishu.com/learnPage/<课程ID>/<班级ID>...`）。
- 已登录的浏览器连接（通常是 Edge + 工作台扩展；不要从头重装或重查登录）。
- 本地进度断点文件 `智慧树课程进度.json`（权威数据源，含 `graphStatus` / `workQueue` / `quizAudit`）。
- 可选：题目与候选答案缓存（按题干文字归档）。

## 执行步骤

1. **恢复连接**：列出实际浏览器标签，确认仍处于登录态；若浏览器工具不可用，如实说明阻碍，不要虚构提交成功。
2. **读断点**：读取进度 JSON，以 `graphStatus` 为准过滤「可练习 / 未完成」项，忽略落后的 `workIndex`。
3. **进入练习**：课程目录 → 知识模块 → 知识单元 → 知识点 → 「去提升 / 提升掌握度」。
4. **读题**：优先读 DOM 定位题号与选项，题号用 `getByRole('treeitem',{name:String(n),exact:true})`；单选用 `list`、多选用 `group`，限定在选项范围内搜索，避免误匹配题干。
5. **填答**：按题干文字匹配答案（**不按题号**）；多选补答时先读勾选状态，避免重复点击取消；切题会自动保存。
6. **查漏**：填完最后一题后切回第 1 题，检查答题卡（`.no-answer`=未答、`.answer`=已答），只补未答项。
7. **提交与计分**：点「提交作业」，读评分页「总题数 N 已答对 M」后才算完成；单凭点过提交不算。
8. **落盘**：把 topic / total / correct / report 写入 `quizAudit`，`graphStatus` 标记「本轮已完成」，保存截图并简短回报（省略冗长进度说明）。
