# 中国大学 MOOC 平台操作经验（实测）

课程示例：网络技术与应用（南京邮电大学 NJUPT-1001639008），学期 tid 1488273477。
题型固定：7 单选 + 5 填空 + 3 判断（部分周为 9 单选 + 3 填空 + 3 判断）= 15 题，每题 2 分，满分 30，
限时 20-30 分钟，有效提交 3 次取最高分。

## 关键机制

| 机制 | 结论 |
| --- | --- |
| 题序与选项顺序 | **每次作答重新随机打乱**，同一题的正确选项字母会变，必须按内容判断，不能记字母 |
| 连续快速点击 | 触发「并发限制，请稍后再试」弹窗，**落后点击可能不落库**，导致提交后出现空题或旧答案 |
| 刷新页面 | 清空所有未提交的勾选，计时器继续走 |
| 图片懒加载 | 含拓扑图/表格的题会先占位白屏，滚动过快会整屏发白，需停一拍再截图 |
| 分数可见性 | 截止前显示「🔒 解锁得分情况」，看不到对错，只能靠提交后回看自己填的答案 |

## 操作纪律

1. 一次点击后先截图确认，不要连点；出现「并发限制」先点确定关掉，再重试该次点击。
2. 全部答完后，**必须从第 1 题滚动到第 15 题逐屏复核**，确认没有空题/串位，再点「提交答案」。
3. 填完空后若页面有重排，重新截图确认坐标再点下一个空。
4. 同一份测验只保留**一个**标签页，多余标签页会加剧并发冲突。
5. 滚动优先用「点空白处 + PageDown」；若 PageUp 失效、页面横向偏移或白屏卡住，先 `tab_focus` 把该标签页置前，再滚动。
6. 页面懒加载会让「含图/表的题」先占位白屏，滚动后**停一拍再截图**，避免坐标错位。

## 提交后核对

- 提交后进入 `#/learn/quizscore?id=<quizId>&aid=<attemptId>` 回看答卷；绿色圆点表示已选，逐题核对。
- 每周显示「有效提交次数 N/3」，点某条记录旁的「查看」可打开该次答卷。
- 若发现空题/错位，评估剩余次数后决定是否重做；重做时题序会再变，仍按题干作答。

## 按题干归档的答案库

建议把每次遇到的题目按「题干要点 → 答案」写入本地答案库（如 `周测答案库.md`），跨周次与跨提交复用。
示例结构见各周作答记录。
