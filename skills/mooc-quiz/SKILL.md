# 中国大学 MOOC 单元测验

## 用途

在中国大学 MOOC 学生端课程内，自动完成各周的「单元测验」（通常 15 题、每题 2 分、满分 30、限时 20-30
分钟、有效提交 3 次取最高分）：逐题读题干判断答案、单点填答、全卷滚动复核、提交并回看答卷核对，
并把答案按题干归档到本地答案库，便于后续周次或重刷复用。

## 适用场景

- 需要逐周完成某门 MOOC 课程的「单元测验 / 测验与作业」。
- 题序与选项顺序每次作答都会随机打乱，必须按题干内容而非字母作答。
- 提交后因平台「并发限制」等导致出现空题或错位，需要回看答卷评估是否重刷。
- 需要沉淀一份「按题干归档」的答案库，跨周次 / 跨提交复用。

## 输入

- 课程 assessments 页面 URL（形如 `https://www.icourse163.org/mooc/learn/<课程ID>/assessments?tid=<学期ID>`）。
- 目标周次与其截止时间（决定是否做、是否值得重刷）。
- 已登录的浏览器连接（Edge + 工作台扩展）。
- 可选：本地答案库（按题干归档）。

## 执行步骤

1. **定位入口**：打开 assessments 页，展开目标周次，点「前往作答」（会新开标签），再点「开始测验」启动计时。
2. **逐题作答**：读题干判断答案（单选 / 填空 / 判断）。**单点一次后先截图确认**，避免连点触发「并发限制」。
3. **填空**：点输入框后 type；若输入框未获焦，改为「点框 → 截图确认焦点 → 再 type」两步，填完核对显示值。
4. **全卷复核**：全部答完后，从第 1 题滚动到第 15 题逐屏核对，确认无空题、无串位，再提交。
5. **提交**：点「提交答案」→ 确认对话框「确定」。
6. **回看答卷**：进入 `quizscore` 页逐题核对已提交答案；若出现空题/错位，评估是否用剩余次数重做。
7. **沉淀**：把本次题目的「题干 → 答案」写入本地答案库（按题干归档，不记字母）。
